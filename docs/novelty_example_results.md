# 문제 독창성 검증 예제: 시간 제약이 최적 유지 목적지를 바꾸는가

예상 심사 질문: "기존 병행 트럭(compound truck) 모형에 도착 시각(release time)과 납기(due date)를 추가했을 뿐인데
새로운 문제라고 할 수 있는가?"

이 검증의 목적은 목적값이 커진다는 사실이 아니라, **시간 제약 때문에 최적해의 구조(유지 목적지, 운송 트럭 간 대기 관계)가
바뀐다**는 점을 계산으로 보이는 것이다.

- 코드: `experiments/novelty_toy_example.py`
- 출력: `outputs/novelty_toy_example.txt`
- 실행: `python experiments/novelty_toy_example.py`

## 1. 예제 구성

| 항목 | 값 |
|---|---|
| 트럭 | 병행 트럭 I1, I2, I3 (출고트럭 없음) |
| 목적지 | D1, D2(세 트럭이 공유), D3(I1만 3단위). 모형 조건 \|I\| + \|F\| = \|D\| 때문에 D3 추가 |
| 화물량 (D1, D2, D3) | I1 (4, 8, 3), I2 (8, 4, 0), I3 (3, 8, 0). 상품 1종, 단위 처리시간 1 |
| 도어 | 일렬 3개, 이송시간 = 도어 번호 차이 |
| 진입·출차 시간 | 모두 1 |
| 기존 설정 | 모든 트럭 도착 0, 납기 없음, 목적식 = 총 작업완료시간 |
| 확장 설정 | 도착 I1 0, I2 0, I3 15 / 연성 납기 I1 20, I2 25, I3 45 / 목적식 = 총 작업완료시간 + λ·총 납기지연 (λ = 1) |

풀이: 가능한 해 36개(유지 목적지 3! × 도어 배정 3!)를 기존 평가기로 전부 평가해 최적해를 구했고,
두 설정 모두 CP-SAT로 같은 최적값을 증명했다(기존 26, 확장 35).

예제 인스턴스는 유지 목적지가 바뀌는 경우를 탐색해서 고른 것이므로 "예시"이다. 일반성은 4절의 무작위 실험으로 뒷받침한다.

## 2. 주 결과 표

| 비교 | 기존 설정 | 확장 설정 (기존 최적 계획 그대로) | 확장 설정 (재최적화) |
|---|---|---|---|
| 트럭별 도착 시각 | 모두 0 | 0, 0, 15 | 0, 0, 15 |
| 연성 납기 | 없음 | 20, 25, 45 | 20, 25, 45 |
| **최적 유지 목적지** | I1→D2, I2→D1, I3→D3 | (기존과 동일) | **I1→D3, I2→D1, I3→D2** |
| **운송 트럭이 기다리는 화물** | I1←I2·I3, I2←I1·I3, I3←I1 | (기존과 동일) | **I1←없음**, I2←I1·I3, I3←I1·I2 |
| **늦은 트럭 I3의 화물을 기다리는 트럭** | I1(8단위), I2(3단위) | I1(8), I2(3) | **I2(3)만** |
| 완료 시각 (I1, I2, I3) | 26, 21, 16 | 41, 36, 31 | 14, 28, 32 |
| 총 작업완료시간 | 26 | 41 | 32 |
| 총 납기지연 | 해당 없음 | 32 | 3 |
| 목적값 J | 26 | 73 | 35 |

해석

- 시간 제약이 생기면 최적해는 늦게 오는 트럭(I3)에 덜 의존하도록 유지 목적지를 다시 고른다.
- 기존 최적해에서는 운송 트럭 두 대(I1, I2)가 I3의 화물 11단위를 기다린다. 확장 최적해에서는 I2 한 대가 3단위만 기다린다.
- I1은 자기만 실어 오는 D3를 유지해서 아무도 기다리지 않으므로 납기(20)를 지킨다(완료 14).
- 목적값 차이(73 대 35, +108.6%)는 이 구조 변화의 결과이다.

## 3. 어느 요소가 구조를 바꾸는가 (분해)

| 설정 | 최적 유지 목적지 | 기존 최적 계획의 목적값 증가 |
|---|---|---|
| 도착 시각만 (납기 없음, 총 작업완료시간) | I1→D1, I2→D3, I3→D2 또는 I1→D3, I2→D1, I3→D2 (동점) | +28.1% (32 → 41) |
| 납기만 (도착 모두 0) | I1→D3, I2→D1, I3→D2 | +18.5% (27 → 32) |
| 도착 시각 + 납기 | I1→D3, I2→D1, I3→D2 | +108.6% (35 → 73) |

- 두 요소 각각만으로도 최적 유지 목적지가 기존(I1→D2, I2→D1, I3→D3)과 달라진다.
- 둘을 결합한 효과(+108.6%)는 각 효과의 합(+46.6%)보다 훨씬 크다. 늦은 도착이 공유 목적지를 통해 다른 운송 트럭으로
  전파되고, 납기가 그 전파된 지연을 트럭마다 비용으로 매기기 때문이다.

## 4. 일반성: 무작위 소형 인스턴스 1,000개

같은 구조(병행 트럭 3대, 공유 목적지 2개 + 소형 D3, 도어 3개)에서 무작위로 생성했다(시드 2026).

| 생성 규칙 | |
|---|---|
| 화물량 | D1, D2는 U{1..8}, I1의 D3는 U{1..3} |
| I3 도착 | {10, 15, 20} |
| 납기 | I1, I2는 {20, 25, 30}, I3는 도착 + {20, 25, 30} |

| 결과 | 값 |
|---|---|
| 기존 최적 유지 목적지 조합이 확장 설정에서 최적이 아닌 비율 | **52.5% (525/1,000)** |
| 그 경우 기존 유지 목적지를 고수할 때 목적값 증가 (도어는 재최적화) | 평균 +33.8%, 중앙값 +28.1%, 최대 +121.9% |

여기서 "바뀐다"는 최적해가 고르는 유지 목적지 조합 집합이 기존과 하나도 겹치지 않는다는 뜻이다(동점 최적해까지 고려).

## 5. 지연 전파: I3 도착을 0 → 40으로 늦출 때

계획을 고정하고 I3 도착 시각만 바꿨다. 납기는 위와 같다.

| I3 도착 | 기존 최적 계획: 납기지연 I1 / I2 / I3 (합) | 확장 최적 계획: 납기지연 I1 / I2 / I3 (합) |
|---:|---|---|
| 0 | 6 / 0 / 0 (6) | 0 / 0 / 0 (0) |
| 10 | 16 / 6 / 0 (22) | 0 / 0 / 0 (0) |
| 15 | 21 / 11 / 0 (32) | 0 / 3 / 0 (3) |
| 20 | 26 / 16 / 0 (42) | 0 / 8 / 0 (8) |
| 30 | 36 / 26 / 1 (63) | 0 / 18 / 2 (20) |
| 40 | 46 / 36 / 11 (93) | 0 / 28 / 12 (40) |

- 기존 계획에서는 I3의 지연이 D1, D2 두 목적지를 통해 I1과 I2 모두에 전파된다(I3 한 대의 지연이 두 트럭의 납기지연으로 중복 청구).
- 확장 계획에서는 I1이 전파 경로에서 빠져 있어 지연이 I2 한 대로만 전파된다.

## 6. 범위와 한계

- 출고트럭이 없는 예제이므로 **운송 순서(출고트럭 도어 순서) 변화는 보여주지 않는다**. 유지 목적지 변화만 보인다.
  출고트럭 순서만 바뀌는 사례는 "납기 순 정렬"로 설명될 수 있어서 독창성 근거로는 유지 목적지 사례가 더 강하다.
- 소형 예제(트럭 3대)라 결과는 메커니즘의 예시이며, 실험 규모(S–XL)에서의 빈도를 측정한 것은 아니다.
- 이 문서는 검증 결과 정리이며 논문 원고에는 아직 반영하지 않았다.
