### R1-2 (2쪽 8행) — 반영

수정 계획: `docs/revision_drafts/R1-2_R1-3_terms_style.md` (2026-11-25). 적용 목록: `docs/revision_drafts/R1-2_R1-3_edit_list.md`. 2026-11-25 반영.

> **원문**: 국문과 영문 용어가 혼용되어, 첫 등장 시 '국문(영문)'으로 병기한 뒤 한쪽으로 통일 권장. 예: 시간창(time window), 탐욕적(greedy) 등

**수정 내용** (80개 항목, 84곳)
- **국문 문장 속 영문을 국문으로 통일**: ablation → 제거 실험(6곳), greedy → 탐욕적(2곳, ε-greedy는 ε-탐욕), reheating → 재가열(3곳), time window → 시간창, simulated annealing → 모의 담금질(SA), ready time → 준비 시각, mixed-service door → 혼합 운영 도어, non-overlap → 비중첩, enforcement literal → 조건부 제약, solver → 솔버, min–max → 최소-최대, horizon → 계획 기간, 2.3절 제목 "Mixed-integer 정식화" → "혼합정수계획 정식화". 결과 서술의 "tabular", "transfer DQN"은 표의 방법 이름 GILS-tabular, GILS-DQN으로 바꿨다.
- **병기를 첫 등장으로 이동**: 수락 규칙(acceptance rule)·탐욕적(greedy)은 3.1절, 최적해·기준해·관측 최선해는 1.1절, 연산자 선택·이웃·연산자 집합은 첫 등장 위치로 옮기고 뒤쪽의 병기는 지웠다.
- **병기가 없던 핵심 용어에 첫 등장 병기 추가**: 크로스도킹, 부분 하역, 입고트럭, 출고트럭, 운송 트럭(carrier), 균등 선택, 학습 기반 선택 정책, 지역탐색, 조정 집합, 시험 집합, 이송시간, 배치 이송, 요인실험, 정확해법, Wilcoxon 부호순위 검정, 전이 학습 DQN 등.
- **같은 개념의 여러 표기를 하나로**: "예약 도착 시각" → "도착 시각", 하강 탐색의 영문 세 가지(best-improvement descent, descent search, best-improvement local search) → 첫 등장의 best-improvement descent 하나, "최선개선 지역탐색" → "최선개선 하강 탐색", 섭동(kick)의 중복 병기 3곳 삭제, "모의 담금질 수락 규칙"·"SA 수락 규칙" → "SA 수락 규칙".
