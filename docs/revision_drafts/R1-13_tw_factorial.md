# R1-13 — 도착 분산 폭과 납기 여유의 독립 영향 실험

- 심사 의견: R1-13, 심사위원 1, 제출본 16쪽 15행. “도착이 퍼지는 폭, 도착 후 납기 여유가 스케줄링 성능에 미치는 영향을 독립적으로 확인할 수 있는 추가 실험을 권장.”
- 관련 의견: R1 총평(도착 시각의 분산 폭 및 납기 여유의 영향을 독립적으로 분석), R2-11(어떤 문제 특성에서 제안 방법이 효과적인지).
- 상태: 실험 완료(2026-11-16, 10,560회). 결과는 아래 “실험 결과” 절. 원고에는 아직 반영하지 않음.

## 왜 지금 실험으로는 답할 수 없는가

주 실험의 시간 제약 수준은 두 가지뿐이고 두 요인이 함께 바뀐다.

| 수준 | 도착 분산 폭 $\rho$ | 납기 여유 $\delta$ |
|---|---:|---:|
| medium | 0.25 | 0.60 |
| tight | 0.50 | 0.35 |

medium에서 tight로 갈 때 도착은 더 퍼지고 납기 여유는 더 짧아진다. 결과의 차이가 어느 요인에서 오는지 분리할 수 없다. 게다가 조건마다 인스턴스가 달라(시드가 조건별로 다름) 조건 간 차이에 인스턴스 차이도 섞여 있다.

## 설계

**두 요인을 세 수준씩 교차한다(3 × 3).**

| | $\delta = 1.00$ | $\delta = 0.60$ | $\delta = 0.35$ |
|---|---|---|---|
| $\rho = 0.10$ | (loose에 해당) | | |
| $\rho = 0.25$ | | (medium에 해당) | |
| $\rho = 0.50$ | | | (tight에 해당) |

- 수준 값은 기존 정의에서 가져왔다. 대각선의 세 칸이 생성기에 정의된 loose, medium, tight와 같은 $(\rho, \delta)$이고, 나머지 여섯 칸이 새 조합이다.
- $\rho$가 클수록 도착이 늦게까지 퍼지고, $\delta$가 작을수록 납기가 빠듯하다.

**같은 인스턴스에서 두 요인만 바꾼다.**

- 한 인스턴스의 아홉 칸은 화물량, 처리시간, 도어 배치, 진입·출차 시간이 모두 같다.
- 도착 시각은 트럭마다 한 번 뽑은 균등 난수 $u_q$를 써서 $r_q = u_q\,\rho H$로 둔다. $\rho$가 바뀌어도 트럭들의 도착 순서와 상대 간격은 같고 전체 폭만 달라진다.
- 납기는 기존과 같이 $\bar d_q = r_q + \delta H$이다.
- 따라서 칸 사이의 차이는 인스턴스 단위로 짝지어 비교할 수 있고, 인스턴스 간 난이도 차이가 상쇄된다.

**규모와 표본**

- 규모 S, M, L. 규모별 인스턴스 20개(주 비교와 같은 수), 확률적 방법은 5회 반복.
- 인스턴스 시드는 400,000번대의 전용 범위를 쓴다. 학습·조정·시험 집합(100,000~399,999)과 겹치지 않는다.
- 방법과 하이퍼파라미터는 확정된 것을 그대로 쓴다. 이 실험의 결과로 어떤 설정도 바꾸지 않는다.

**비교 방법**

| 방법 | 역할 |
|---|---|
| VAA | 구성 휴리스틱만 적용한 초기해 |
| Extended SA-RL5 (1,000회) | 원 모델 해법을 식 (16)으로 확장한 비교 대상 |
| GILS-uniform (1,000회) | 제안 방법(기본 선택 정책) |

CP-SAT는 넣지 않는다. 시간 제약 조건에서는 S에서도 최적성이 거의 증명되지 않아(S-medium 1/20, S-tight 0/20) 기준으로 쓰기 어렵고, 180개 인스턴스 × 9칸에 300초씩이면 계산 시간이 지나치게 길다.

**실행 건수:** 3 규모 × 20 인스턴스 × 9칸 × (VAA 1 + SA-RL5 5 + GILS 5) = 5,940건.

## 측정

“스케줄링 성능”을 두 가지로 본다.

1. **문제의 어려움이 어떻게 달라지는가:** GILS 해의 총 작업완료시간과 총 납기지연. 규모가 달라도 비교할 수 있게 $H$로 나눈 값($C_{\max}/H$, $\sum T_q/H$)도 본다.
2. **제안 방법의 이점이 어떻게 달라지는가:** GILS의 VAA 대비, Extended SA-RL5 대비 개선율. Table 5의 Gain과 같은 정의로 $100 \times (J_{\text{other}} - J_{\text{GILS}})/J_{\text{GILS}}$이며 양수이면 GILS가 좋다.

**통계**

- 칸별: GILS와 Extended SA-RL5의 인스턴스 반복 평균에 대한 양측 Wilcoxon 부호순위 검정(20쌍). 기존 표들과 같다.
- 요인별 주효과: 한 요인의 각 수준에서 다른 요인의 세 수준을 평균한 값.
- 양 끝 수준의 비교: 인스턴스별로 다른 요인을 평균한 뒤, $\rho$ 0.10 대 0.50, $\delta$ 1.00 대 0.35를 짝지어 검정(규모 3개를 합쳐 60쌍).

## 해석할 때 주의할 점 (실행 전에 정해 둠)

- 이 실험의 인스턴스는 주 실험(Table 4)의 인스턴스와 다르다. (0.25, 0.60) 칸과 (0.50, 0.35) 칸의 값이 Table 4의 medium, tight와 같지 않다. 크기와 방향이 비슷한지만 확인한다.
- 목적값은 총 작업완료시간과 총 납기지연의 합이어서 납기지연이 커지는 칸에서는 목적값 자체가 커지고, 같은 절대 개선이 더 작은 비율로 나타난다. 개선율과 함께 절대 차이도 본다.
- 최적해 대비 격차는 알 수 없다. 이 실험이 보여 주는 것은 비교 방법 대비 상대적 이점이다.
- 결과가 어떻게 나오든 그대로 보고한다. 어떤 칸에서 GILS의 이점이 작거나 없으면 그 조건을 한계로 적는다.

## 설계 변경 (2026-11-16): 3 × 3 → 4 × 4

처음 설계(3 × 3)는 모든 칸에서 두 요인이 함께 켜져 있어 “도착 분산만”, “납기만”인 조건이 없었다. 심사위원이 4.2절의 “두 방향으로 동시에 어려워진다”는 문장에 대해 “독립적으로”를 요구했으므로, 각 요인에 “꺼짐” 수준을 더했다.

- $\rho \in \{0, 0.10, 0.25, 0.50\}$: $\rho = 0$은 모든 트럭이 시각 0에 도착.
- $\delta \in \{\infty, 1.00, 0.60, 0.35\}$: $\delta = \infty$는 납기 없음(목적값은 총 작업완료시간, 가중치 0).
- $(0, \infty)$가 원 모델 설정, 첫 행이 “납기만”, 첫 열이 “도착 분산만”, 안쪽 아홉 칸이 교차 조건.
- 실행: 3 규모 × 20 인스턴스 × 16칸 × 11회 = 10,560회.

### 해석

1. **두 요인은 문제를 다르게 어렵게 한다.** 도착 분산은 도어가 트럭을 기다리게 만들어 총 작업완료시간을 늘린다. 납기 여유는 총 작업완료시간을 거의 바꾸지 않고 납기지연만 늘린다. 제출본의 tight 조건은 두 효과가 겹친 결과이다.
2. **GILS의 이점은 모든 조건에서 유지된다.** 한 요인만 켠 조건, 두 요인이 겹친 조건 모두에서 SA-RL5보다 유의하게 좋다.
3. **상대 이점은 납기 여유가 적당할 때 가장 크다.** $\delta = 1.00$에서 약 3%로, 납기지연이 생기지만 배정과 순서로 피할 수 있는 범위이기 때문으로 보인다. 납기가 빠듯해지면 절대 이점은 계속 커지지만(0.092 → 0.107), 어떤 해법으로도 피할 수 없는 납기지연이 목적값을 키워 비율은 작아진다.
4. **도착 분산이 커지면 이점이 조금 줄어든다.** 도착이 퍼질수록 트럭이 늦게 오는 시간이 스케줄을 지배해 해법이 바꿀 수 있는 부분이 줄어든다.
5. R2-11(어떤 문제 특성에서 효과적인가)의 근거로 쓸 수 있다: “납기가 존재하되 배정으로 피할 수 있는 수준일 때 제안 방법의 이점이 가장 크다.”

### 원고 반영안

- 4.2절: “tight는 두 방향으로 동시에 어려워지는 조건이다” 뒤에 두 요인을 분리한 실험을 5장에서 보고한다는 문장을 넣는다.
- 5장 새 소절(5.5 또는 5.2 뒤): 위 4 × 4 표 하나(SA-RL5 대비 개선)와 3~4문장. 한 요인만 켠 조건의 총 작업완료시간과 납기지연은 본문 문장으로.
- 6장: 해석 3번을 R2-11 논의에 쓴다.
