# R1-1, R1-18, R2-11, R2-14 — CP-SAT 서술 정정안 (M 조건에 실행 가능해가 있음, L은 없음)

- 배경: 제출본은 "M의 시간 제약 조건과 L의 모든 조건에서 CP-SAT가 제한시간 안에 실행 가능해를 반환하지 못했다"고 썼다. 2026-07-06 기록은 Mac이 잠들어 실제 계산 시간이 21~355초였다. 600초를 온전히 준 재실행에서 M은 여섯 건 모두 실행 가능해를 반환했고, L은 여섯 건 모두 반환하지 못했다.
- 재실행: 2026-11-13, 2026-11-15. 12건 모두 유효(계산 시간과 경과 시간 일치). 한 건씩 순차 실행, 8스레드, 600초.
- 근거 자료: `outputs/cpsat_rerun.jsonl`, `experiments/cpsat_rerun.py`, 로그 `outputs/logs/cpsat_rerun_*.log`
- 상태(2026-11-16): 재실행과 수치 계산 완료. 문안 확정. 본문과 답변서에는 아직 반영하지 않음. M-none 행은 재실행 기록으로 통일하기로 정했다(아래 "결정: M-none 행").

## 결정: M-none 행은 재실행 기록으로 통일한다 (2026-11-16)

M-none은 7월 기록도 유효하지만(607초, 604초), 인스턴스 1에서 재실행이 더 좋은 기준해를 찾았다. 더 좋은 기준해를 기준으로 삼고, M의 세 조건을 같은 실행 방식의 기록으로 맞춘다.
