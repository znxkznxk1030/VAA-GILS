- 작성일: 2026-11-25
- 기준 원고: `paper/jkiie_submit_body.tex`(2026-11-25, R1-7·R2-4 반영 후), `paper/jkiie_submit_body.docx`. 아래 행 번호(L)는 이 tex 기준이다.
- 두 지적 모두 원고 전체의 국문 문장에 관한 것이라 함께 처리한다. 같은 문장을 두 번 고치지 않도록 한 번에 고친다.

## 1. 심사 의견

> **R1-2** (투고본 2쪽 8행): 국문과 영문 용어가 혼용되어, 첫 등장 시 '국문(영문)'으로 병기한 뒤 한쪽으로 통일 권장. 예: 시간창(time window), 탐욕적(greedy) 등

> **R1-3** (투고본 2쪽 14행): 전반적으로 구어체가 많이 사용되어 학술체로 수정 권장. 예: 두 요소를 빼면, 연산자 하나를 뽑아, 번호매기나 등

## 2. 요약

- **R1-2**: 용어 대조표(5절)를 만들어 용어마다 국문 하나를 정한다. 본문 첫 등장에만 "국문(영문)"으로 병기하고 이후에는 국문만 쓴다. 고유명사, 알고리즘·소프트웨어 이름, 실험 조건·방법 이름은 영문을 유지한다.
- **R1-3**: 구어 표현 대체표(6절)에 따라 고유어 동사와 구어 연결 표현을 학술 표현으로 바꾼다. 심사위원의 예시 세 곳을 포함해 약 80곳이다.
- 수정량은 두 항목을 합쳐 약 150곳으로 예상한다. Word에서는 바뀐 낱말만 노란색으로 표시한다.

## 4. 원칙

### 4.1 용어 (R1-2)

1. **국문 용어가 정착된 개념**: 본문 첫 등장에 "국문(영문)"으로 쓰고 이후에는 국문만 쓴다. 국문 초록은 따로 읽히므로 초록의 첫 등장에도 병기한다.
2. **약어가 있는 개념**: 첫 등장에 "국문(영문, 약어)"로 쓰고 이후에는 약어를 쓴다. 예: 모의 담금질(simulated annealing, SA).
3. **영문을 유지하는 것**
   - 고유명사와 알고리즘·소프트웨어 이름: Q-learning, DQN, ALNS, CP-SAT, OR-Tools, Wilcoxon, Holm, Python
   - 표준 기호: big-M
   - 표·그림과 같은 식별자: 실험 조건(none, medium, tight, S-none …), 방법 이름(VAA-GILS, GILS-uniform, GILS-tabular, GILS-DQN, Paper-SA-RL5, Extended SA-RL5), 표의 열·집합 이름(Gain, critical, full)
4. **같은 개념에는 국문 하나**만 쓴다(3.1절 (3)의 표기를 하나로).
5. 절 첫머리의 굵은 항목 이름(예: "\textbf{하강 탐색(descent search).}")에 있던 중복 병기는 지운다. 첫 등장 한 곳에만 남긴다.

### 4.2 문체 (R1-3)

1. 일상 동사 대신 학술 동사를 쓴다(6절 대체표).
2. 구어 연결 표현을 문어 표현으로 바꾼다: "~해서/~라서" → "~하여/~이므로", "~위해서다" → "~위함이다", "이렇게" → "이와 같이", 보조동사 "~어 주다"는 지운다.
3. 판단을 나타내는 "본다"는 뜻에 따라 "가정한다", "고려한다", "해석한다"로 바꾼다.
4. 정도 부사는 수치나 학술 표현으로 바꾼다: "조금만" → "소폭", "잘" → "적절히".
5. **바꾸지 않는 것**: 종결어미 "~다"(국문 학술지 표준), "~지만", "따라서", 학술 문장에서 통용되는 "찾다", "나누다", "따르다", "다루다", 기호에 값을 정하는 "~로 둔다".

## 7. 작업 방법

1. **수정 목록 작성**: 5·6절에 따라 고칠 문장 전체를 "수정 전 / 수정 후"로 정리한 목록(`docs/revision_drafts/R1-2_R1-3_edit_list.md`)을 만든다. 국문 본문을 처음부터 끝까지 한 번 더 읽어 3절 스크립트에 걸리지 않은 표현을 추가한다. 이 목록이 답변서의 근거가 된다.
2. **tex 적용**: 목록대로 고치고, 고친 문단마다 `% R1-2` 또는 `% R1-3` 주석을 남긴다. 컴파일 후 3절의 점검 스크립트를 다시 돌려 남은 영문·구어 표현이 4.1절 3항의 예외뿐인지 확인한다.
3. **Word 적용**
   - 같은 목록을 문단 단위로 적용한다. 낱말이 run 경계에 걸리면 그 문단만 따로 처리한다(서식 스킬의 "run 경계" 함정).
   - **바뀐 낱말만 노란색으로 표시한다.** 문장 전체를 표시하면 다른 심사 의견으로 고친 부분과 구분되지 않는다.
   - 지운 병기(예: L364의 "(greedy)")는 표시할 수 없으므로 답변서에 적는다.
   - 확인: 문단 단위 비교로 의도한 문단만 바뀌었는지 보고, 서식 점검(`check_format.py`)을 돌린다.
4. **쪽 번호**: 문장 길이가 달라져 쪽이 바뀔 수 있으므로 답변서와 스프레드시트의 위치를 다시 계산한다.

## 9. 답변서 문안 초안

> **R1-2**
> 지적에 감사드립니다. 원고 전체의 전문 용어를 점검하여, 국문 용어가 있는 개념은 처음 나올 때 '국문(영문)'으로 병기하고 이후에는 국문으로 통일하였습니다(예: 시간창(time window), 탐욕적(greedy) 수락 규칙, 재가열(reheating), 제거 실험(ablation)). 같은 개념을 여러 표현으로 쓰던 곳(예: 하강 탐색, 도착 시각)도 하나의 용어로 정리하였습니다. 알고리즘과 소프트웨어 이름(Q-learning, CP-SAT 등)과 표에 쓰인 실험 조건·방법 이름은 표와 본문의 대응을 위해 영문을 유지하였습니다.

> **R1-3**
> 지적에 감사드립니다. 예시로 주신 표현을 포함하여 원고 전반의 구어체 표현을 학술체로 수정하였습니다(예: "두 요소를 빼면" → "두 요소를 제외하면", "연산자 하나를 뽑아" → "연산자 하나를 선택하여", "번호매기나" → "번호를 부여하였으나"). 이 밖에 "고르다", "쓰다", "바꾸다", "늘다" 등의 일상 표현을 "선택하다", "사용하다", "변경하다", "증가하다" 등으로 고쳤습니다.
