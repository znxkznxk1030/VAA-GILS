## 1. 심사 의견

> **R1-5** (투고본 4쪽 17행): '관련 연구'가 소제목인지 본문의 일부인지 모호하여, '관련 연구를 살펴보면'으로 연결하거나 별도의 소제목으로 구분하는 방식으로 수정 권장

> **R2-5**: 논문 전반적으로 가독성을 개선할 필요가 있습니다. 예를 들어, Page 4의 관련 연구 및 Page 12의 하강 탐색 등에 대한 설명에서는 새로운 개념이나 방법론의 명칭이 본문과 충분히 구분되지 않은 상태에서 바로 설명이 이어지는 부분이 있어, 해당 용어가 새로운 항목의 제목인지 또는 본문의 일부인지 명확하지 않은 경우가 있습니다. 소제목, 문단 구분, 글꼴 등을 적절히 활용하여 논문의 구조를 보다 명확하게 제시하는 것을 제안 드립니다.

## 2. 원인과 해결 방향

**원인**: 문단 첫머리에 "용어. 설명"처럼 항목 이름을 두는 방식을 쓰고 있다. 이 이름이 본문과 같은 글꼴로 이어져 있다.

- tex에서는 일반 글자로 되어 있다.
- Word에서도 이름과 본문이 같은 서식의 한 덩어리(run)로 들어 있다.
- 그래서 독자가 이것을 제목으로 알아보기 어렵다.

**원고 전체 점검 결과**: 이런 곳은 10곳이다.

| 위치 | tex 행 | 문단 첫머리 | 심사 의견에서 지목 |
|---|---|---|---|
| 1장 | 94 | 관련 연구. | R1-5, R2-5 |
| 3장 | 305 | 초기해 구성(initial solution construction). | |
| 3장 | 330 | 하강 탐색(descent search). | R2-5 |
| 3장 | 334 | 반복 탐색(iterated search). | |

| 3장 | 404 | 선택 정책(selection policy)과 원 모델의 비교. | |

1장과 3장은 장 안에 하위 절이 하나도 없어 긴 장이 문단만으로 이어진다. 5.2절은 이미 하위 절 안이라 문단 이름만 구분되면 충분하다.

**해결 방향**: 두 단계로 나눈다.

1. 1장과 3장에 하위 절(소제목)을 둔다.
2. 하위 절 안의 항목 이름은 **굵은 글씨**로 통일한다. 마침표 뒤에 본문을 같은 줄에 이어 쓰는 형식이다.

R1-5가 제시한 두 방법 가운데 "별도의 소제목으로 구분"을 택한다. R2-5가 원고 전체의 구조를 요청하므로 1장만 문장으로 연결하는 것보다 일관된다.

| 새 절 | 범위 (현재 tex 행) | 바뀌는 것 |

| 1.1 연구 배경과 기여 | 50–90 (배경, 원 모델의 두 가정, 기여 세 가지) | 장 제목 바로 뒤에 소제목만 추가 |

- **"본 논문의 구성은 …" 문단** (현재 1장 끝, 142행): 1.2절 끝에 두면 관련 연구의 일부처럼 읽힌다. 1.1절 끝으로 옮기는 것을 권한다. 옮기지 않는 안은 7절 결정 2에 둔다.

### 3.2 3장 (R2-5)

3장은 R2-10 반영 후의 구성을 기준으로 소제목을 정한다. 하위 절을 항목마다 하나씩 만들면 3줄짜리 절(하강 탐색)이 생긴다. 그래서 세 절로 묶고 절 안의 항목은 굵은 글씨로 구분한다.

| 새 절 | 들어가는 내용 | 절 안의 굵은 항목 이름 |
|---|---|---|
| (3장 도입) | VAA-GILS의 개요 문단 (300–303행), 소제목 없음 | |
| 3.1 초기해 구성 | VAA, 식 (17)–(19), 수치 예시 | 소제목이 항목 이름을 대신하므로 "초기해 구성(…)." 삭제 |
| 3.2 탐색 절차 | 하강 탐색, 반복 탐색, 섭동 재시작, Algorithm 1, Figure 4 | **하강 탐색(descent search).** **반복 탐색(iterated search).** **섭동 재시작(kick restart).** |
| 3.3 연산자 집합과 선택 | 기본 이웃 7종, 병목 정의와 유도 연산자 4종, 연산자 선택(R2-10 후 2문장) | **기본 이웃(generic neighborhoods).** **병목 유도 연산자(bottleneck-guided operators).** **연산자 선택(operator selection).** |

- **3.3절의 문단 나누기**: 현재 "연산자 집합" 문단은 기본 이웃과 유도 연산자가 한 문단에 있다. 병목 정의가 시작되는 곳("% R1-12" 주석 위치)에서 나누어 두 항목으로 만든다.
- **R2-10 반영 후**: "선택 정책과 원 모델의 비교" 문단과 Table 2는 4.3절로 옮겨지므로 3장에 남지 않는다. R2-10을 반영하지 않는 경우의 처리는 7절 결정 4에 둔다.
- **순서**: 3.2절의 항목 순서(하강 → 반복 → 섭동)는 그대로 둔다. 반복 탐색이 하강 탐색을 부르므로 하강 탐색을 먼저 정의하는 현재 순서가 자연스럽다.

## 4. 번호와 참조에 미치는 영향

## 5. Word 작업

- **소제목**: 제목 2 스타일(`w:pStyle w:val="2"`) 단락으로 새로 넣고 노란색으로 표시한다. 기존 "2.1 기호 정의" 단락의 서식을 복사한다.
- **굵은 항목 이름**: 문단 첫 run을 "항목 이름."과 나머지로 나누고, 항목 이름 run에 `<w:b/>`와 하이라이트를 넣는다.
- **삭제한 글자** ("관련 연구.", "초기해 구성(…)."): Word에서 하이라이트로 표시할 수 없으므로 답변서에 적는다.
- **문단 나누기** (기여 세 문단, 연산자 집합 두 문단): 기존 run을 나눠 새 단락으로 옮긴다. 문장은 바꾸지 않는다.
- **확인**: 수정 전 파일과 문단 단위로 비교해 문장 내용이 바뀌지 않았는지 본다(제목 추가와 삭제한 항목 이름만 차이). LibreOffice로 렌더링해 제목 서식이 2.1절 등과 같은지 확인한다.
