### R2-12 Δ_bo 계산식

> 상세 수정안: `docs/revision_drafts/R2-12_delta_bo_formula.md` (2026-11-22). 아래 초안의 기호($\mathcal N$, $\mathcal R$)는 기존 기호와 겹쳐 상세안에서 $\Pi$, $\mathcal X$로 바꾸었다.

**심사 의견**: Table 4에서 사용되는 Δ_b0의 계산 방법을 수식으로 함께 제시 (심사평의 Δ_b0는 원고의 Δ_bo, best observed)

**현재 원고 (4.3절, 512–516행)**: 관측 최선해와 Δ_bo를 문장으로만 정의한다.

**수정안**: 516행 뒤에 식을 넣는다(번호 없는 식).
> 인스턴스 $n$의 관측 최선해 목적값을 $J_n^{bo}$, 어떤 방법의 $r$번째 실행 목적값을 $J_{n,r}$이라 할 때
> \[\Delta_{bo}=\frac{100}{|\mathcal N|\,|\mathcal R|}\sum_{n\in\mathcal N}\sum_{r\in\mathcal R}\frac{J_{n,r}-J_n^{bo}}{J_n^{bo}}\ (\%)\]
> 이며, $\mathcal N$은 조건에 속한 인스턴스, $\mathcal R$은 반복 실행의 집합이다.

**반영 전 확인**: Table 4의 Δ_bo가 실행 단위 평균(위 식)인지, 인스턴스별 반복 평균의 평균인지 `experiments/k1_stats.py`, `k1_summary.py`에서 확인한다. 두 값은 거의 같지만 식은 실제 계산과 일치해야 한다. 코드의 다른 위치(`k1_stats.py` 201행)는 실행 단위로 계산하고 있다.

### R2-13 Table 5의 Gain 계산식

**심사 의견**: Table 5의 Gain 역시 구체적인 계산식 … 어떤 방법론을 기준으로 성능 개선율을 계산한 것인지 수식을 통해 명확하게

**현재 원고**: Table 5 캡션(585행)에 "Gain is the mean relative objective difference in favor of GILS-uniform"이라고만 있다.

**코드에서 확인한 정의** (`experiments/budget_fairness.py` 96–111행): 인스턴스별로 5회 반복의 평균 목적값을 구한 뒤 $100\times(\bar J^{\text{SA}}_n-\bar J^{\text{GILS}}_n)/\bar J^{\text{GILS}}_n$를 계산하고 인스턴스에 대해 평균한다.

**수정안**: 5.1절 Table 5를 소개하는 문장 뒤(또는 Table 5 캡션)에 식을 넣는다.
> \[\text{Gain}=\frac{100}{|\mathcal N|}\sum_{n\in\mathcal N}\frac{\bar J_n^{\text{SA-RL5}}-\bar J_n^{\text{GILS}}}{\bar J_n^{\text{GILS}}}\ (\%)\]
> 여기서 $\bar J_n$은 인스턴스 $n$에서 5회 반복의 평균 목적값이다. 기준은 GILS-uniform이며 양수이면 GILS-uniform이 좋다.

- 캡션에도 같은 정의를 한 줄로 적는다(영문).
- 같은 정의를 쓰는 곳을 함께 밝힌다: Table 10과 Table A1의 "vs VAA(%)", "vs SA-RL5(%)".

**함께 정리할 점 (부호와 단위가 표마다 다름)**

| 표 | 열 | 정의 | 양수의 뜻 |
|---|---|---|---|
| Table 4 | vs CP-SAT(%) | $(J-J^{\text{CP}})/J^{\text{CP}}$ | 해당 방법이 CP-SAT 기준해보다 나쁨 |
| Table 5 | Gain(%) | $(J^{\text{SA}}-J^{\text{GILS}})/J^{\text{GILS}}$ | GILS가 좋음 |
| Table 6, 7, 9 | Gain(%p), Degradation(%p), Mean diff.(%p) | 인스턴스별 반복 평균의 상대 차이(%) | 표마다 캡션에 적힌 방향 |
| Table 10, A1 | vs VAA, vs SA-RL5(%) | Table 5와 같음 | GILS가 좋음 |

- Table 4는 부호 방향이 반대이므로 캡션에 정의를 한 줄 넣는다. 지금은 "음수이면 CP-SAT 기준해보다 좋다"는 설명만 있다.

**정할 것**: Table 6, 7, 9의 단위 표기를 %로 바꿀지. 권고는 %로 통일하고 본문의 %p를 같이 고치는 것. 바꾸지 않는다면 "%p"가 Δ_bo의 차이로 읽힐 수 있음을 캡션에서 밝힌다.

| 변수 영역 | 기호 표에 "1이면 …, 아니면 0"만 있음 | 영역 제약이 식으로 없음 | 2.3절 끝에 $x_{idm},z_{fdm},b_{fgm}\in\{0,1\}$, $U_i,C_i,S_f,C_f,C_{\max},T_q\ge0$을 번호 없는 식으로 추가 |

- 보조 변수 $X_{im}$, $Z_{fm}$, $Z_{fd}$는 기호 표에서 정의식으로 주어져 있다. 2.3절에도 "정의에 따라 계산되는 보조 변수"라고 한 줄 적는다.
- 식 번호는 바꾸지 않는다. 변수 영역 식에는 번호를 붙이지 않는다.

**Word 작업**: (1)–(15)는 v4 때부터의 Word 수식 개체다. 범위를 고치는 식은 tex에서 Word 수식으로 다시 만들어 교체한다. 식의 모양(크기, 정렬, 번호 위치)이 기존 식과 맞는지 렌더링으로 확인한다.

### R2-8 λ = 1을 실험 설정으로 이동

**심사 의견**: λ의 값은 실험의 parameter setting에 해당하므로 식 (16)에서는 일반적인 목적함수를 제시하고 실험 부분에서 설정값을 설명

**현재 원고**
- 2.4절 288행: $\min\ J=C_{\max}+\lambda\sum_{q\in I\cup F}T_q,\qquad \lambda=1 \qquad (16)$
- 289행: λ의 의미 설명, "(5.4절)" 참조
- 5.4절 705행: λ = 1을 채택한 근거(민감도 분석)

**수정안**
1. 식 (16)에서 "λ = 1"을 지운다: $\min\ J=C_{\max}+\lambda\sum_{q\in I\cup F}T_q \qquad (16)$
2. 289행의 설명은 유지하고 "실험에서 사용한 값은 4.3절에 적는다"를 덧붙인다.
3. 4.3절(실험 설정)에 문장을 추가한다.
   > 모든 실험에서 납기지연 벌점 계수는 $\lambda=1$을 사용한다. 이 값은 조정 집합에서 $\lambda$를 바꿔 가며 총 작업완료시간과 납기지연의 균형을 비교한 결과(5.4절)에 따라 정하였다.
4. 시간 제약이 없는 조건(none)에서는 납기지연이 0이므로 λ와 무관하다는 점을 같은 문장에 밝힌다(실험 코드도 none에서는 가중치 0을 쓴다).

**영향 확인**: 원고에서 "식 (16)"을 참조하는 곳(4.3절 Extended SA-RL5 설명, 5.4절)이 λ = 1을 전제로 읽히지 않는지 본다. 5.4절은 λ를 바꾸는 분석이므로 오히려 일관성이 좋아진다.
