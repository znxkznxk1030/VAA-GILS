# SCI(E)급 논문화 계획: 연속 도착 병행 트럭 크로스도크의 동적 디스패칭 (research/rl)

작성 2026-10-12. **JKIIE 원고(VAA-GILS)와 별개의 연구로 진행한다(사용자 결정, 2026-10-12).** 현재 결과는 [stream_rl_research.md](stream_rl_research.md), 후속 제안은
[stream_rl_roadmap_2026-10-12.md](stream_rl_roadmap_2026-10-12.md), 원문 검증은 [refs_verification_stream.md](refs_verification_stream.md).

## 0. 문제의식

RL이 더 좋은 결과를 내더라도 지금 상태로는 다음 비판을 피하기 어렵다.

| 지점 | 예상 비판 |
|---|---|
| 비교 대상 | FCFS-VAA는 단순 규칙, Cyclic 계열은 정적 방법을 억지로 끼운 것 → "허수아비 비교" |
| 절대 기준 | 모든 수치가 규칙 대비 상대값 → 최적에서 얼마나 먼지 모름 |
| 데이터 | 자체 생성기의 합성 데이터, 학습과 평가가 같은 생성기 |
| 모형 가정 | 병행 트럭의 현장 근거 없음(원 논문 Shahmardan & Sajadieh 2020도 없음, S00 검증), 리드타임 목적식은 실무 지표가 아님(Ladier & Alpan 2016에서 관리자 0%, S01 검증) |
| 방법 새로움 | Rollout + 증류는 Bertsekas 계열에서 확립된 방법 |

따라서 RL 고도화보다 **결과가 어떤 비교와 데이터에서도 버티도록 받침을 먼저 깐다**.

## 1. 진행 전략: 세 갈래

### 1.1 기준을 강하게 ("이긴 상대가 강했다")

1. **튜닝한 매개변수형 규칙**(최우선, 가장 쉬움): 대기 화물, 납기 여유, 이송 거리, 보류 임계값 등의 가중합 점수 규칙을 tuning 풀에서
   탐색해 최선을 고른다. 이 비교를 넘어야 "학습이 필요하다"가 성립한다.
2. **롤링 호라이즌 재최적화**: 사건마다 현재 상태에서 일정 구간을 최적화하고 첫 결정만 실행(문헌상 표준 비교 대상).
3. **사후 최적과 하한**: 짧은 구간의 사후 최적해(미래를 다 아는 CP-SAT)와 대기 없는 하한으로 절대 격차와 정보 가치 분해.

2와 3은 **일반화 정적 모형(목적지당 운송 트럭 여러 대 허용) 하나**로 해결된다. 미래를 모두 넣으면 사후 최적 기준해,
현재 상태만 넣고 반복해 풀면 롤링 호라이즌 비교 대상이 된다. → 우선순위 최상.

### 1.2 데이터 의심 줄이기 ("어떤 데이터에서도 결론이 같다")

1. 산업 수치 보정 시나리오(Ladier & Alpan 2016의 도어 수, 하루 트럭 수, 집중·분산 도착; 모든 수치에 출처 쪽 번호)
2. 강건성 격자(병행 트럭 비율, 부하, 피크 강도, SLA, 도어 수, 수요 쏠림). 결론이 무너지는 영역도 보고
3. 표준 특수 경우: 병행 트럭 비율 0(입고 전용 + 출고 전용 트럭). 시뮬레이터에 입고 전용 트럭 유형 추가 필요
4. 외부 생성 인스턴스(Torbali & Alpan 공개 데이터)에서 평가. 3이 선행 조건
5. 기업 데이터는 보너스(확보 시 실제 도착 순서 재생 사례 연구). 연구 성립의 전제로 두지 않음

### 1.3 주장 다듬기 (데이터와 무관하게 성립하는 질문)

1. 정적 최적화의 한계: 사이클별 최적해(CP-SAT)조차 상태 기반 정책보다 약 30% 나쁨 → 손실은 풀이기가 아니라 틀(구조적 결론)
2. lookahead와 정보의 가치: 규칙 → Rollout → 사후 최적 격차 분해
3. 빠른 정책으로의 이전: Rollout 이득 중 얼마를 1 ms 정책으로 옮길 수 있는가(방법의 새로움이 아니라 적용과 측정이 기여)

## 3. 기여 구성 (3+1)

1. **문제**: 병행 트럭 크로스도크의 연속 도착 동적 디스패칭을 MDP로 정식화. 근거는 기반 논문이 향후 과제로 명시한
   "병행 트럭 수 ≫ 도어 수, 목적지당 여러 트럭, 불확실성"(Shahmardan & Sajadieh 2020 결론, S00). 일반화 정적 모형도 제시.
2. **구조적 통찰**: 정적 최적화를 연속 흐름에 적용할 때의 손실(사이클별 최적해로도 약 30%)과 원인(사이클 대기, 운송 빈도 경직,
   계획-실행 불일치) 분해. 이미 결과 있음, 데이터 의존성 낮음. 사이클 풀이기는 원 논문의 VAA·SA-RL5(Shahmardan & Sajadieh 2020)와
   CP-SAT(사이클별 최적해)만 쓰고 **VAA-GILS(JKIIE 방법)는 제외**한다. 시험 결과에서 Cyclic-GILS는 Cyclic-SA-RL5·Cyclic-CPSAT와
   1% 안이었으므로 빼도 결론이 바뀌지 않는다.
3. **방법**(하나만 주 기여로):
   - (a) 가치망으로 절단한 rollout + 그래프 정책망 증류: 산업 규모에서 Rollout이 너무 느린 문제(현재 L에서 결정당 평균 0.2초)를
     학습된 가치로 줄이고, 그래프 정책망으로 규모 일반화. "산업 규모에서 왜 학습이 필요한가"에 대한 답.
   - (b) 시뮬레이터 상태 복제를 이용한 공통 난수 반사실 이점 추정: 정책 경사 RL의 신호 잡음 감소.
   - 권장: (a)를 주 방법, (b)를 구성 요소로. MARL은 도어 막힘을 겨냥한 결정을 추가하지 않는 한 제외.
4. **실무 통찰**: 피크 강도, 병행 트럭 비율, 도착 정보 수준에 따라 어떤 정책이 언제 유리한가(산업 보정 시나리오 기반).

## 4. 필수 실험 목록

| 묶음 | 내용 | 막는 비판 |
|---|---|---|
| E1 비교 대상 | 튜닝한 매개변수형 규칙, 롤링 호라이즌(일반화 모형 + GILS/CP-SAT), 문헌 온라인 규칙(Larbi et al. 2011 계열), 그래프 정책망 PPO(공정 튜닝) | 허수아비 비교 |
| E2 절대 기준 | 대기 없는 하한, 소형 사후 최적(CP-SAT), 정보 가치 분해 | 최적에서 얼마나 먼가 |
| E3 규모 | 도어 32–48 산업 규모(학습은 소형, 평가는 대형), 결정 시간 | 실무 적용성, 일반화 |
| E4 데이터 | 산업 보정 시나리오(택배·식품·유통), 비정상 도착(집중·분산), 강건성 격자, 병행 트럭 0, 외부 인스턴스 | 자체 생성기 의존 |
| E5 분석 | 구성 요소 제거, 학습 곡선, 정책 행동 해석(보류, 운송 빈도 조정), λ 민감도 | 블랙박스, 목적식 임의성 |
| E6 통계·재현 | 셀별 결과, 효과 크기·신뢰구간, 다중 비교 보정, 코드·인스턴스 공개 | 신뢰성 |

## 7. 주의할 점

- **JKIIE 원고와의 관계(별개 진행)**: 이 논문은 JKIIE의 후속편으로 쓰지 않는다. 출발점은 원 논문(Shahmardan & Sajadieh 2020)의
  향후 과제이고, 비교 대상도 원 논문 방법(VAA, SA-RL5)·문헌 기준선·CP-SAT로 구성한다. VAA-GILS, 유도 연산자, JKIIE의 시간창 확장 표현
  ("Extended-SA-RL5" 같은 명칭 포함)은 쓰지 않고, 납기 항을 포함한 SA-RL5는 이 논문 안에서 독립적으로 정의한다. JKIIE 결과를 수치로
  재사용하지 않으므로 중복 게재 문제는 없으며, 게재 후 관련 연구로 한 줄 인용할지는 그때 결정한다.
- **병행 트럭 근거**: 원 논문도 현장 근거가 없으므로 "선행 연구가 정의한 운영 방식(수거·배송 겸용 차량, 순회 수거, 반품 회수)"으로
  서술하고, 병행 트럭 0 특수 경우로 결과의 일반성을 보완한다. 보강 문헌 S21–S23(Ertek 2012, Morais et al. 2014, Tarantilis 2013) 확인 예정.
- **목적식**: 납기 준수를 주 지표로 앞세우고(출발 마감은 Ladier & Alpan에서 8곳 중 6곳), 리드타임 항은 크로스도크의 재고 최소화·24시간 내
  출고 목적으로 정당화. 혼잡·도어 이용률을 보조 지표로 보고.
- **인용**: Ladier & Alpan은 2016년 논문이 두 편(Omega 62; C&IE 99) → 2016a/2016b 구분. "혼합 운용 9곳 중 5곳"은 Omega 2016 p.156을
  직접 인용(Shahmardan & Sajadieh 2020의 2018 인용은 오류).
- **지도교수 협의**: "RL 고도화 금지"는 석사논문(JKIIE) 범위 지침이었다. 이 연구를 SCI(E) 논문으로 진행할지, 학위논문과 어떻게 나눌지 먼저 상의.
