## 1. 비교 기준 확장 실험 결과 (S·M, 시험 60개 스트림)

L은 사이클 CP-SAT 계산량 때문에 제외했다(사용자 결정).

| 비교 기준 | RL-API | Rollout |
|---|---:|---:|
| FCFS-VAA (규칙) | −11.5% | −15.0% |
| Cyclic-VAA (VAA만) | −35.9% | −38.3% |
| Cyclic-SA-RL5 (원 논문) | −29.9% | −32.5% |
| Cyclic-GILS | −29.7% | −32.2% |
| Cyclic-CPSAT (사이클별 최적해) | −29.7% | −32.3% |
| SPT-VAA | −11.0% | −14.7% |

- 사이클 풀이 품질(최적 대비 격차 VAA 19.2% / SA-RL5 0.63% / GILS 0.06% / CP-SAT 0)이 달라도 연속 운영 성능은
  SA-RL5 이상에서 1% 안에서만 바뀐다. 사이클 방식의 손실(+28–33%)은 풀이기가 아니라 사이클 틀에서 나온다.
- RL-API는 모든 사이클 방식보다 60/60 스트림에서 좋다(p = 1.7e-11).

## 2. 현재 RL의 한계 (다음 방법의 출발점)

1. PPO 실패: 결정 효과가 긴 시간에 섞이고 보상 잡음이 커서 정책 경사 신호가 약함
2. 증류 정책(RL-API)은 교사(Rollout)를 넘지 못하고 이득의 약 2/3만 얻음. 학습하지 않은 L에서 효과 감소(−8.9% 대 −20.6%)
3. 도어 막힘(운송 트럭이 화물을 기다리며 도어 점유, 도어 시간의 약 27%)을 어떤 정책도 줄이지 못함

## 3. 다음 RL 방법 제안 (미착수)

| 순위 | 제안 | 겨냥하는 한계 | 판정 기준 (tuning 풀) |
|---|---|---|---|
| 1 | AlphaZero식 정책-가치망 + 짧은 MCTS + 반복 증류(expert iteration), 몸통은 그래프·어텐션 정책망 | 2(교사를 못 넘음), 규모 일반화 | 2세대가 1세대 Rollout보다 3% 이상 좋으면 계속, 아니면 "한 단계 정책 개선으로 충분"으로 봉인. 학습 안 한 L에서 Rollout과의 격차 절반 이상 축소 |
| 2 | 증류 정책에서 출발하는 RL 미세조정: 상태 복제(fork) + 공통 난수로 행동 간 이점 직접 추정, 장기 평균 비용 actor-critic | 1(신호 잡음) | 교사보다 좋아지면 순수 RL 기여, 아니면 PPO 실패 원인 확정 |
| 3 | 행동 확장: 운송 트럭 적재 시작 시점·출발 결정 추가(계층형) | 3(도어 막힘) | 도어 막힘 비율 감소 여부 |
| 4 | 환경 확장: 시간대별 도착률 변동, 도착 예정 정보 공개 | 규칙 대비 RL 우위가 드러나는 조건, 현실성 | |

### MARL을 넣는 경우

- 설계: 목적지 에이전트(적재 시작 시점, 유지 목적지 입찰) + 도어 에이전트(받을 트럭 선택), 중앙 학습·분산 실행(MAPPO 계열),
  같은 종류 에이전트는 파라미터 공유(규모 일반화), 충돌은 순차 결정이나 입찰로 해소.
- 방법론 차별점 후보: COMA는 반사실 기준선을 학습된 Q로 근사하지만, 본 시뮬레이터는 fork로 "이 에이전트만 다른 행동"을
  직접 시뮬레이션할 수 있다(유사 선례 미발견).
- 위험: 단일 디스패처가 전체 정보를 보는 설정에서는 중앙 정책이 MARL보다 나쁠 이유가 없어 "왜 MARL인가"에 답하기 어렵다.
- 권장 순서: 제안 3(적재 시작 결정)을 단일 에이전트로 먼저 검증 → 여지가 있으면 목적지·도어 에이전트 MARL로 확장.
- 판정: 같은 정보의 단일 에이전트 정책과 비슷하면 확장 중단. 도어 막힘이 줄지 않으면 목적지 에이전트의 의미 없음.

## 4. 문헌 조사 요약 (상세: literature_scan_stream_rl.md, 제목·초록 수준)

- 크로스도크에서 학습은 정적 문제 탐색 보조(SA 이웃 선택, Q-learning ALNS, 신경망 pricing)뿐. 연속 도착 디스패칭 정책 학습은 미발견.
- 동적 크로스도크는 우선순위 규칙, 롤링 호라이즌, 규칙 기반 다중 에이전트(Torbali & Alpan 2023). 병행 트럭 + 연속 도착 결합 미발견.
- 크로스도크 MARL 미발견. 가장 가까운 선례는 Amazon 분류센터 DRMARL(2025), 항만 MARL.
- Rollout + 증류는 Bertsekas 계열 근사 정책 반복(multiagent rollout 2020이 거의 같은 구조) → 새 알고리즘이라고 주장하지 말 것.
  기여는 새 문제 설정 + 정적 최적화 한계 정량화 + 확립된 방법의 첫 적용.
- 외국 학술지용으로 롤링 호라이즌 재최적화 기준선 필요. 서지 미확인 2026 롤링 호라이즌 논문(확인 수준 C)이 원문 대조 1순위.

## 5. 기준해 설계 (제안, 미착수)

현재 수치는 모두 FCFS-VAA 대비 상대값이라 최적성 격차를 말할 수 없다. JKIIE의 "증명 최적 / CP-SAT 기준해 / 관측 최선" 구분을
옮겨 세 층으로 둔다.

| 층 | 기준 | 의미 | 비용 |
|---|---|---|---|
| ① 하한 | 대기 없는 하한(화물마다 진입 + 하역 + 최소 이송 + 적재 + 출차, 납기지연 0), 필요하면 용량 기반 하한 병기 | 진짜 하한 → 절대 격차. 고부하에서 느슨 | 작음 |
| ② 사후 최적 기준해 | S 짧은 구간(트럭 20–40대)을 미래를 모두 아는 상태에서 CP-SAT로 풀이 | 정보 가치 + 최적성 격차. 목적지당 운송 트럭 여러 대를 허용하는 모형 새로 정식화 필요 | 큼 |
| ③ 관측 최선 | 스트림별 모든 방법의 최선, 또는 계산을 늘린 Rollout(표본 32, 구간 2 SLA) | 도달 가능한 수준 | 없음–중간 |

실무 기준으로 FCFS-VAA(0%)와 Cyclic-CPSAT(정적 방법 최선)를 계속 함께 보고한다.
권장 순서: ③ → ① → (①이 고부하에서 30% 이상 느슨하면) ②. "optimal"은 ②에서 증명된 경우에만 쓴다.
